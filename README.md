# QuakeNet – Earthquake Early Warning & Emergency Response Network

A CSE 421 Computer Networks project designed using Cisco Packet Tracer.

## Project Overview

QuakeNet is a network infrastructure designed to support earthquake monitoring, emergency communication, and disaster response.

## Technologies & Concepts

* VLSM Subnetting
* DHCP & DHCP Relay
* RIPv2
* Static Routing
* Route Failover
* DNS
* Web Services
* Email Communication
* Network Redundancy

## Project File

The complete Cisco Packet Tracer network is available here:

**`QuakeNet_CSE421.pkt`**

Download the `.pkt` file and open it using Cisco Packet Tracer to explore the network topology and configurations.
